## 🔍 Quick Reference

### **Technology Stack**
- **Frontend:** React 19.2.4, Vite 8.0.1, React Router DOM 7.14.0
- **Styling:** TailwindCSS 4.2.2, shadcn/ui 4.1.2, Lucide React 1.7.0
- **Libraries:** Axios, React Player, JWT Decode, jsPDF, html2canvas
- **Dev Tools:** ESLint, PostCSS, Autoprefixer

*(See [PROJECT SUMMARY](../PROJECT_SUMMARY.md) for complete tech stack details)*

### **Project Statistics**
- **Files:** 40+ JSX components
- **Lines of Code:** 10,000+ lines
- **Routes:** 14 routes (5 public, 4 student, 5 instructor)
- **Components:** 28+ reusable components
- **Completion:** 75% (6 of 10 phases)
- **Build Status:** ✅ Zero errors, production-ready

### **Key Features Completed**
✅ Public landing page and course catalog  
✅ Authentication system (JWT-based)  
✅ Student dashboard with progress tracking  
✅ Video course player (ReactPlayer)  
✅ Quiz system with instant grading  
✅ Certificate generation with PDF download  
✅ Instructor dashboard with full CRUD  
✅ Lesson manager with modules  
✅ Quiz builder for instructors  
✅ Cloudinary integration for uploads
